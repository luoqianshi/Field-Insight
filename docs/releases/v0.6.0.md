# 田间智瞰 v0.6.0

> 里程碑版本 · 本仓库首个 Git tag 与首份 GitHub Release · 发布日期 2026-11-28
> 主题：移除「新建数据集」功能，数据集管理收敛为扫描载入 + 统一管理分析

「田间智瞰」是基于无人机（UAV）图像的大田农作物智能监测系统，覆盖 数据管理 → 数据处理 → 数据集管理 → 算法广场 四模块，提供 Web 与 Windows 桌面两种形态。本版本是 `0.x` 快速迭代期的一个重要里程碑：数据集管理模块的范围正式收敛，数据治理能力推迟独立立项。

## 主要变更

### 数据集管理收敛（移除「新建数据集」）

- 删除 `DatasetNew.vue` 构建模式（4 步向导「基础信息/标注格式/拆分策略/目录结构预览」为纯 mock、提交禁用占位），页面重写为 `DatasetImport.vue`「载入数据集」：扫描预检（COCO/YOLO/VOC 格式识别 + 轻量统计）→ 可选名称/描述 → 原位导入注册。
- 路由变更：`/dataset/dataset-new` → `/dataset/dataset-import`。
- `Datasets.vue` 删除「新建数据集」按钮（保留「载入数据集」），状态徽标删除「构建中」分支，来源列固定「导入」；`DatasetDetail.vue` 同步清理。
- 首页快速入口「构建数据集」→「载入数据集」，模块卡描述改为「统一管理与统计分析已标注完备的数据集资产」。
- `api/datasets.ts` 类型收窄：`DatasetSource = 'imported'`、`status = 'ready'`。

### 后端清理

- 删除 `backend/mock/datasets.json`（V1 时代数据集 mock，自 V0.5.0 真实实现后无任何代码引用）。
- 删除 `config.py` 死配置 `MOCK_DIR` / `MOCK_IMAGES_DIR`。
- 数据集 API 无需改动：扫描/导入/统计报告/样本浏览能力全部保留。

### 决策记录

数据集构建、标注、质量评估、拆分与多格式导出推迟到后续专门版本，作为「数据治理」模块统一处理。与 PRD v6 的出入对照见 `docs/sdd/specs/2026-11-27-dataset-creation-removal-and-governance-deferral.md`。

## 破坏性变更

- 前端路由 `/dataset/dataset-new` 已移除，更名为 `/dataset/dataset-import`（旧路径无兜底路由，直接访问会渲染空白页）。
- 后端 REST API 无破坏性变更。

## 安装与运行

- **安装包**：双击运行，向导式安装、当前用户级（无需管理员权限）、支持自定义安装目录；自动创建桌面与开始菜单快捷方式「田间智瞰」。默认安装目录 `%LOCALAPPDATA%\Programs\TianJianZhiKan`。
- **便携版**：解压 zip 后双击 `win-unpacked\TianJianZhiKan.exe` 直接运行。
- **未签名提示（重要）**：安装包未做代码签名，Windows SmartScreen 会提示「未知发布者」，属预期现象。点击 **「更多信息 → 仍要运行」** 即可继续。
- **业务数据位置**：可写数据根固定为 `%LOCALAPPDATA%\TianJianZhiKan`（与安装位置解耦），含 data/output/datasets/results/models/config/logs。**卸载不删除业务数据**；可在「设置 → 数据存储 → 更改位置」整体迁移到其他磁盘。

## 系统要求

- Windows 10/11 x64
- 磁盘：安装后约 1.1 GB（Electron 运行时 + CPU 版 torch）
- 推理：仅 CPU（为保证可分发体积，发行版不含 CUDA）；首次启动后端就绪约 2.6–3.0 秒
