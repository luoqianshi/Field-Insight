# 数据集「新建/构建」功能移除说明（PRD 出入对照）

> 日期：2026-11-27 ｜ 关联版本：V0.6.0 ｜ 状态：已决策并实施
> 决策：**正式移除【数据集管理】模块中「新建数据集」相关功能设定**；当前版本仅提供**扫描载入已标注完备的数据集**，实现数据集资产的统一管理与统计分析。数据集构建、标注、质量评估等能力推迟到后续专门版本，作为**「数据治理」模块**统一处理。

## 一、背景与决策

- 原设计（PRD v6 第四章）中，数据集管理模块包含两条链路：
  1. **导入/载入链路**：扫描路径预检 → 导入注册（COCO/YOLO/VOC）→ 统计报告 → 浏览/删除；
  2. **构建链路**：从处理产物图片目录 + 外部标注目录构建标准化数据集（异步任务、拆分策略、目录生成）。
- 实际演进中，构建链路从未实现后端（`DatasetNew.vue` 构建向导提交按钮自 V0.5.0 起即为禁用的「第二阶段实现」占位，提交逻辑为纯前端 mock 提示）。
- 2026-11-27 正式决策：**放弃在本模块内提供数据集新建/构建**。原因：数据采集、清洗、标注、质量评估属于数据治理全生命周期能力，与「已标注数据集的资产化管理与分析」职责不同，宜作为独立模块统筹设计，避免半成品入口长期挂载在界面上。

## 二、当前版本（V0.6.0）数据集管理模块范围

| 能力 | 状态 |
|---|---|
| 路径预检扫描（格式识别 + 轻量统计） | ✅ 保留（`POST /api/datasets/scan`） |
| 已标注数据集导入注册（原位引用，不复制） | ✅ 保留（`POST /api/datasets/import`） |
| `datasets/` 目录自动发现注册 | ✅ 保留 |
| 列表/详情/统计报告（ECharts）/样本分页浏览/预览/删除 | ✅ 保留 |
| 新建数据集（构建 4 步向导） | ❌ 移除（前端入口与 mock 向导删除） |
| 数据集构建 / 拆分 / 多格式导出 | ⏭ 推迟至「数据治理」模块 |
| 数据集标注 / 质量评估 | ⏭ 推迟至「数据治理」模块 |

## 三、与 PRD 基线的出入对照（PRD v6 第四章）

PRD v7 声明「模块三需求基线与 v6 一致」，故以 PRD v6 为对照基准。以下条目与本次改动存在出入，**以本说明为准**（PRD 历史版本不回改）：

| PRD v6 条目 | 原描述 | 本次处置 |
|---|---|---|
| 第四章 API 表（`POST /api/datasets` 构建数据集，异步任务 `{source_image_dir, source_annotation_dir, name, format, split_ratio, split_granularity}` 返回 task_id） | 构建数据集端点 | **从未实现，正式移除该设定**；后端无构建端点，无需删码 |
| 页面设计（DatasetNew.vue 双模式：导入可用 / 构建 4 步向导禁用预留） | 双 tab 页面 | 构建向导（基础信息/标注格式/拆分策略/目录结构预览）整体删除；页面重命名为 **DatasetImport.vue（载入数据集）**，路由 `/dataset/dataset-new` → `/dataset/dataset-import` |
| 首页快速入口「构建数据集」卡片 | 直达构建页 | 改为「**载入数据集**」，直达导入页；模块卡描述同步改为「统一管理与统计分析已标注完备的数据集资产」 |
| 验收标准 25「构建拆分验证」（7:2:1 拆分、原图级粒度防泄露、list.csv/dataset_meta.json 生成） | 构建功能验收 | 移除；拆分与元数据生成能力随「数据治理」模块重新验收 |
| 验收标准 39「端到端流程验证」（…→导入/**构建**数据集→格式转换导出→…） | 全链路含构建 | 流程改为「外部标注完备后**直接导入**」，格式转换导出随「数据治理」模块另验 |
| 「阶段2→阶段3」流程描述（模块三以处理产物为输入**构建**数据集） | 构建衔接 | 改为：处理结果经外部标注后，由模块三**扫描载入**已标注完备数据集 |

## 四、本次删除清单

### 前端
- `frontend/src/views/dataset/DatasetNew.vue`：删除（构建 4 步向导 mock + 模式切换）；导入逻辑迁入新文件 `DatasetImport.vue`，页面更名「载入数据集」。
- `frontend/src/views/dataset/Datasets.vue`：删除「新建数据集」按钮（仅保留「载入数据集」）；状态徽标删除「构建中」分支；来源列固定显示「导入」（后端 `source` 恒为 `imported`）。
- `frontend/src/views/dataset/DatasetDetail.vue`：状态徽标删除「构建中」分支；来源显示固定「导入」。
- `frontend/src/views/index/Index.vue`：快速入口「构建数据集」→「载入数据集」；模块卡描述更新。
- `frontend/src/router/index.ts`：路由 `dataset-new` → `dataset-import`。
- `frontend/src/api/datasets.ts`：`DatasetSource` 收窄为 `'imported'`；`status` 收窄为 `'ready'`（移除 `'building' | 'failed'` mock 时代联合类型）。

### 后端
- `backend/mock/datasets.json`：删除（V1 时代数据集 mock 数据，自 V0.5.0 真实实现后无任何代码引用）。
- `backend/config.py`：删除死配置 `MOCK_DIR` / `MOCK_IMAGES_DIR`（定义后从未被引用）。
- 后端 API 无需改动：`datasets_api.py` 仅含扫描/导入/查询/报告/删除端点，本就无构建端点。

### 保留说明
- `backend/mock/batches.json`：属**数据管理模块**的 V1 mock 遗留（同样无代码引用），不在本次数据集范围内，暂不处置。
- `DatasetDetail.vue` 的目录树示意、`list.csv`/`dataset_meta.json` 展示为已导入数据集的格式说明，非构建功能，保留。

## 五、后续规划（「数据治理」模块，候选）

以下能力自本说明起从数据集管理模块的范围声明中移除，待独立立项：
1. 数据集构建：处理产物图片 + 标注文件 → 标准化数据集目录（拆分策略、原图级粒度防泄露、list.csv / dataset_meta.json）。
2. 数据集标注：对接/内置标注工具链的衔接能力。
3. 数据集质量评估：标注质量、类别失衡、样本分布体检。
4. 拆分与多格式导出：train/val/test 重拆分、COCO/YOLO/VOC 互转导出。
