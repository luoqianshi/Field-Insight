## 一、需求背景

用户对「注册新架次」表单（`BatchNew.vue`）提出三项更新需求：

1. **推荐的架次名称格式更新**为：`作物_采集日期_采集高度_编号`（原为 `作物_采集日期_编号`）。
2. **作物类型**允许用户自行新增新的作物类型（原来硬编码为四个固定选项）。
3. **图片文件夹路径**允许点击按钮弹出系统原生文件夹选择对话框来选择路径（原来是纯手输绝对路径）。

三项需求均涉及前端表单交互与后端 API 联动。

---

## 二、方案设计

### 2.1 架次名称推荐格式（含编号段）

- 前端占位符与帮助文字改为 `作物_采集日期_采集高度_编号`，示例 `sugarcane_20260805_5_001`。
- 后端自动发现正则扩展为四段可选：`crop_date_altitude[m][_seq]`，其中 `seq` 编号段为可选，`m` 后缀亦可选，以同时兼容旧的 `sugarcane_20250419_5m` 数据目录与新格式。

### 2.2 作物类型自定义新增

- 将硬编码 `<select>`（仅四选项）替换为 `<input list>` + `<datalist>` 组合：既可从预设下拉中选择，也可自由输入任意新作物。
- 新增作物通过 `watch` 监听自动收集，并持久化到浏览器 `localStorage`（键 `uav_vis_custom_crops`），下次进入页面仍保留。
- 后端 `crop_type` 字段本就是自由字符串（`create_batch` 无枚举校验），因此后端无需改动；新作物同时会随架次记录本身落库到 `data/batches.yaml`。

### 2.3 图片文件夹路径原生选择对话框

- 后端新增 `POST /api/batches/pick-folder` 接口，调用 Python 标准库 `tkinter` 的 `filedialog.askdirectory()` 弹出系统原生文件夹选择窗口，返回所选绝对路径。
- tkinter 缺失时返回 500 并提示手动输入；用户取消选择时返回 200 + `cancelled: true`（不算错误）。
- 前端新增「选择」按钮（位于「扫描」按钮左侧，次要样式），选中路径后自动填入输入框并联动触发 `doScan()` 校验，省去用户手动点击扫描。

```ts
async function doPick() {
  picking.value = true
  errorMsg.value = ''
  successMsg.value = ''
  try {
    const res = await batchesApi.pickFolder()
    if (res.data?.cancelled) return
    const picked = res.data?.path
    if (!picked) { errorMsg.value = '未获取到所选路径'; return }
    imagePath.value = picked
    await doScan()
  } catch (e: any) {
    errorMsg.value = e.message || '打开文件夹对话框失败'
  } finally {
    picking.value = false
  }
}
```

```python
@batches_bp.route("/api/batches/pick-folder", methods=["POST"])
def pick_folder():
    """POST /api/batches/pick-folder → 弹出系统原生文件夹选择对话框，返回所选绝对路径。"""
    try:
        import tkinter as tk
        from tkinter import filedialog
    except ImportError:
        return _error("当前环境未安装 tkinter，无法弹出系统对话框，请手动输入路径", 500)
    try:
        root = tk.Tk()
        root.withdraw()
        root.attributes('-topmost', True)
        folder = filedialog.askdirectory(title="选择 UAV 架次图片文件夹")
        root.destroy()
    except Exception as exc:
        return _error(f"打开文件夹对话框失败: {exc}", 500)
    if not folder:
        return jsonify({"success": False, "data": {"cancelled": True}, "message": "用户取消选择"}), 200
    return jsonify({"success": True, "data": {"path": folder.replace("\\", "/")}, "message": "文件夹选择成功"})
```

## 五、经验总结

- **命名格式向后兼容**：扩展正则时用 `(?:m)?` 与 `(?:_seq)?` 两个可选分组，可同时兼容新旧目录，避免破坏已存在的 `data/sugarcane_20250419_*` 自动发现结果。
- **自定义选项的轻量持久化**：自定义作物用浏览器 `localStorage` 而非后端新增配置，与既有「自定义字段不入库」惯例一致，实现成本低且不引入后端迁移。
- **原生对话框的取舍**：tkinter 是 Python 标准库（Windows 默认自带），实现原生系统弹窗最贴近用户预期；但其依赖桌面 GUI、会阻塞后端进程直至用户关闭窗口，因此在缺失时返回 500 + 明确提示，前端保留手动输入作为兜底。
- **取消语义处理**：用户点「取消」返回空字符串，前端视为「无操作」不覆盖已输入路径，也不当作错误上报，交互更友好。
