## 五、经验总结

1. **字体高级感**：Inter + Noto Sans SC 组合是中文后台系统中兼顾现代感与中文可读性的稳妥选择；务必使用国内 CDN 镜像避免加载失败，并开启 `tnum` 让表格数字等宽。
2. **图标统一**：用中央 SVG Icon 组件替代 Font Awesome 能显著提升一致性，得益于 `stroke-width`、端点圆角等参数统一，视觉更精致；逐步替换过程中应先扩充组件内置图标集再替换引用。
3. **品牌色统一**：品牌主色变更需同步检查 tailwind 色阶与 styles.css 中所有硬编码颜色，避免出现新旧色混用；Emerald（#10B981）与白色/浅灰背景搭配更显克制高级。
4. **参数默认值**：默认值声明集中于组件顶部 `ref(...)`，便于维护；修改默认值后应同步核对提交 payload 与后端默认配置的一致性。
