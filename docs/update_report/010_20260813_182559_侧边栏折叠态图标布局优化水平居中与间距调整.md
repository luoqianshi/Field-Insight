## 一、需求背景

用户反馈：侧边栏收缩（折叠）之后，各个图标之间的相对位置看起来有些逼仄、偏斜，希望优化这些图标在折叠后的展示效果，使其更自然，而不是像当前这样略显偏移。

经分析，折叠态（宽度 56px）存在以下具体问题：

1. **图标水平偏右**：折叠时 `.nav-item` 仍保留 `padding: 9px 12px`，叠加 nav 容器的 `px-3`（12px 左右内边距），导致图标实际比侧边栏中心线偏右约 5px，视觉上"偏"。
2. **垂直逼仄**：导航项间距仅 `space-y-0.5`（2px），折叠后图标几乎相邻，显得拥挤。
3. **顶部溢出**：56px 宽度无法同时容纳 "Logo(32px) + 间距 + 折叠按钮(28px)"，导致 Logo 被裁切、折叠按钮被挤出可视区域。
4. **激活指示条偏移**：折叠态下，激活项左侧的 3px 竖条指示器紧贴窄块边缘，视觉重心不居中。

## 二、方案设计

### 2.1 折叠态导航项改为"居中方形图标块"
- 新增专用样式类 `nav-item--icon-only`：
  - `justify-content: center` + `margin: 0 auto` 实现水平居中；
  - `width/height: 40px`、`padding: 0` 让图标块呈现为规整的正方形，消除原有横向 padding 造成的偏右；
  - 图标尺寸在折叠态放大到 20px，视觉更饱满。
- 折叠态 nav 容器内边距改为 `px-2`（8px），间距加大到 `space-y-1.5`（6px），使图标之间节奏舒展。
- 折叠态隐藏激活项左侧竖条指示器（`.nav-item--icon-only.active::before { display: none }`），仅保留居中的圆角浅绿底块，避免重心偏移。

### 2.2 顶部 Logo 区按折叠态差异化渲染
- 折叠态：顶部改为单个居中的 Logo 按钮（40×40，内含 32×32 图标），点击即可展开侧边栏，彻底解决原有"Logo 被裁切 + 按钮被挤出"的溢出问题。
- 展开态：保持原有"Logo + 标题 + 折叠按钮"一行布局不变。

### 2.3 底部用户区居中
- 折叠态下移除用户区内边距（`px-0 py-0`），使 32px 圆形头像在 56px 栏内精确水平居中。

### 2.4 交互细节
- 折叠态导航项仍通过原生 `title` 属性提供名称提示；hover 背景为居中的方形圆角块，与激活态形状一致。

## 五、经验总结

1. **折叠导航的"偏"通常来自未清除的横向 padding**：折叠后导航项若仍保留 `padding` 并叠加容器 padding，图标必然偏离中心线。用 `margin: 0 auto` + `justify-content: center` + `padding: 0` 归一，可保证精确居中。
2. **窄栏下"能放多少内容"要预先核算**：56px 宽度放不下 Logo + 折叠按钮，与其压缩裁切，不如改为"折叠态顶部仅一个可点击切换的 Logo 按钮"，既解决布局又保留入口。
3. **激活指示条在窄态需收敛**：展开态使用左侧竖条指示器合理，但折叠态它会让视觉重心偏移，折叠时应隐藏竖条、仅保留居中圆角底块。
4. **间距即节奏**：将折叠态项间距从 2px 提升到 6px，图标块从"贴边方块"变为"居中舒展方块"，观感明显改善。
