## 一、需求背景

用户针对「单图作物检测」与「作物计数」两个模块的图片展示结果区域提出新增图片查看交互需求，具体要点如下：

1. 在图片展示区域内单击任意图片时，应立即触发弹窗机制，以模态窗口形式展示该图片的高清大图版本。
2. 弹窗需包含以下核心元素：
   - 关闭按钮；
   - 图片缩放控制功能（支持鼠标滚轮缩放或手势缩放）；
   - 图片拖动功能（允许用户在弹窗内移动图片）。
3. 弹窗覆盖层背景需半透明，以突出显示大图内容，同时禁用弹窗外页面的交互操作。
4. 需保证在主流浏览器（Chrome、Firefox、Safari、Edge）中兼容运行。
5. 弹窗打开/关闭动画需平滑过渡，图片加载过程中需显示适当的加载状态提示。

## 二、方案设计

### 2.1 组件复用策略

经排查，作物检测（`frontend/src/views/algo/Detect.vue`）与作物计数（`frontend/src/views/algo/Counting.vue`）两个页面均通过同一组件 `frontend/src/components/algo/DetectionViewer.vue` 来渲染「原图 + 检测结果图」双栏展示区域。因此**只需在 `DetectionViewer` 内集成一次弹窗，即可同时覆盖两个模块**，避免重复实现，保持交互一致。

### 2.2 独立可复用弹窗组件

新建 `ImageViewer.vue` 作为通用高清图片查看器，与展示逻辑解耦，便于后续其它模块复用：

- 使用 Vue 3 `<Teleport to="body">` 将弹窗渲染到 body 顶层，规避父容器 `overflow` 对弹窗层级的限制。
- 使用 `v-model:visible` 双向控制打开/关闭。
- 交互能力全部收敛在组件内部：滚轮缩放、触摸缩放、拖拽平移、双击缩放、旋转、键盘快捷键、加载/错误状态、打开/关闭动画、body 滚动锁定。

### 2.3 点击触发与悬停提示

在 `DetectionViewer` 的每个图片容器上加 `@click`（仅当存在图片 src 时启用），并新增「点击放大」角标提示与悬停「查看大图」浮层，提升可发现性。

### 2.4 交互细节设计

- **缩放中心**：滚轮缩放以鼠标当前位置为缩放原点，通过调整 translate 保持鼠标指向的像素点不漂移。
- **拖拽与点击区分**：记录按下点与移动距离，超过 3px 记为拖拽，拖拽后不触发「点击空白关闭」，避免误关。
- **状态重置**：每次打开前重置 scale/translate/rotation，关闭时移除事件监听，避免下次打开继承上次位置与缩放。
- **降级策略**：为兼顾移动端，同时实现单指拖拽 + 双指捏合缩放的手势逻辑。

## 三、改动详情

### 3.1 新增组件：`frontend/src/components/common/ImageViewer.vue`

通用高清图片查看器弹窗组件，核心能力：

- 变换状态：`scale` / `translateX` / `translateY` / `rotation`，通过 `computed` 生成 CSS `transform`。
- 滚轮缩放（以鼠标为中心）：
  ```ts
  function onWheel(e: WheelEvent) {
    if (!imgEl.value || !containerEl.value) return
    e.preventDefault()
    const rect = containerEl.value.getBoundingClientRect()
    const mouseX = e.clientX - rect.left - rect.width / 2
    const mouseY = e.clientY - rect.top - rect.height / 2
    const delta = e.deltaY < 0 ? 1 + SCALE_STEP : 1 - SCALE_STEP
    const newScale = Math.max(MIN_SCALE, Math.min(MAX_SCALE, scale.value * delta))
    const ratio = newScale / scale.value
    translateX.value = mouseX - (mouseX - translateX.value) * ratio
    translateY.value = mouseY - (mouseY - translateY.value) * ratio
    scale.value = newScale
  }
  ```
- 鼠标拖拽平移 + 点击/拖拽区分：
  ```ts
  function onMouseMove(e: MouseEvent) {
    if (!isDragging.value) return
    const dx = e.clientX - dragStartX
    const dy = e.clientY - dragStartY
    if (Math.abs(dx) > 3 || Math.abs(dy) > 3) dragMoved = true
    translateX.value = startTranslateX + dx
    translateY.value = startTranslateY + dy
  }
  function onContainerClick(e: MouseEvent) {
    if (dragMoved) { dragMoved = false; return }
    if (e.target === containerEl.value) close()
  }
  ```
- 工具栏：缩小 / 缩放百分比 / 放大 / 左右旋转 / 关闭。
- 键盘快捷键：`Esc` 关闭、`+/-` 缩放、`0` 重置。
- 触摸手势：单指拖拽 + 双指捏合缩放。
- 加载状态与错误状态提示。
- 打开/关闭时锁定 body 滚动：
  ```ts
  watch(() => props.visible, async (v) => {
    if (v) {
      resetState()
      document.body.style.overflow = 'hidden'
      window.addEventListener('keydown', onKeyDown)
      await nextTick()
    } else {
      document.body.style.overflow = ''
      window.removeEventListener('keydown', onKeyDown)
      window.removeEventListener('mousemove', onMouseMove)
      window.removeEventListener('mouseup', onMouseUp)
    }
  })
  ```
- 半透明遮罩：`bg-black/80 backdrop-blur-sm`（80% 黑色 + 毛玻璃模糊）。
- 过渡动画：以 `Transition` 包裹，`iv-fade` 淡入淡出 + 图片缩放过渡。

## 五、经验总结

1. **复用点前置排查收益高**：本次先定位到两个页面共用 `DetectionViewer`，因此一次集成即覆盖两个模块，避免重复实现。开发前应先做组件复用关系排查。
2. **点击与拖拽需区分**：缩放查看器中，拖拽平移与点击关闭是冲突手势，需通过移动阈值（3px）区分，拖拽后不触发关闭。
3. **状态重置与监听清理**：模态类组件务必在打开前重置缩放/位移/旋转状态，在关闭与卸载时移除全局事件监听，防止状态串扰与内存泄漏（参考既有图片预览经验教训）。
4. **Teleport 提升层级**：弹窗用 `<Teleport to="body">` 渲染，避免被父容器裁剪，保证遮罩全屏覆盖并禁用页面交互。
